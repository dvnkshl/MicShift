# MicShift brand mark

The selected MicShift brand mark is the microphone containing two opposing
left/right arrows. It represents the automatic handoff between the preferred
wireless input and the fallback Mac input.

## Usage

- Use the brand mark for the website hero, release artwork, repository avatar,
  DMG artwork, and future application icon.
- Keep the existing live menu-bar status artwork for the running utility. Those
  icons encode connected battery level and offline state, which the static
  brand mark does not.
- Prefer the 128 px or larger exports for marketing. The 32 px export is the
  smallest recommended brand use; at 18 px the opposing arrows lose clarity.

remain native AppKit template images so macOS can tint and dim them correctly.
